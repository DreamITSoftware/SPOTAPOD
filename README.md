# SPOTAPOD
SPOTAPOD is a term primarily associated with exposing and tracking "engagement pods" on social media platforms, particularly LinkedIn.  I built my own custom browser that runs on MAC, Linux/Ubuntu, and Windows.

The browser creates a log of all requests and responses from a any site.  No information is sent back to my servers.  Chromium is used as a browser resource.  It's up to all of us to put the HUMAN back into HUMANity.
