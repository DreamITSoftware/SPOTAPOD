# Books

## DIGITAL BOUGHTulism: POONAMI

*A Teenagers Field Guide to Fake Social Media*, by Daniel Hall, with a
foreword by Lonnee Rey. It follows "Top 100 List of Lies on Social
Media."

![Cover](digital-boughtulism-poonami/cover.jpg)

The book is written for teenagers. It explains fake engagement and
vanity metrics in plain language, and it draws on the kind of findings
documented in this repo.
