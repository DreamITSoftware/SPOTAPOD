# The Line I Won't Cross: No Raw Data, Ever

### Three datasets, hundreds of thousands of records, and not one raw row has ever been committed to this project's public repository

Of every rule governing this project, this is the one with no exceptions.

## What the rule says

No raw data file, not a row, not a redacted excerpt, not a "representative sample," is ever committed to the public repository, published in an article, or included in any output this project produces. Everything that leaves this project is an aggregate: a count, a rate, a percentage, a distribution. The raw files themselves live only in a private, access-controlled location and are never checked into version control.

## Why no single illustrative example

The most tempting exception to a rule like this is the smallest one: "surely one anonymized example post, to make the finding concrete, can't hurt." It can. A single real post, even with the author's name removed, can often be re-identified through the content itself: a distinctive phrase, a specific combination of details, or a timestamp that narrows down who could have posted it. Aggregate statistics don't carry that risk because no specific record is left to trace back to anyone. Once an exception is made for "just one example," the privacy protection depends on that example being untraceable, which is a weaker guarantee than never publishing an example.

## What this costs the writing

This limits how vivid these articles can be. "One post received 88,028 likes on zero recorded views" is a finding this project can and does report, because it's a count derived from the data, not the post itself. This project will never publish a screenshot of that exact post, however illustrative, because a screenshot is the raw record, and the raw record must not leave the project.

## Why an absolute line instead of case-by-case judgment

A case-by-case standard erodes over time. Each exception looks reasonable in isolation, and together they leave a policy that is absolute in name only. A rule with no carve-out mechanism is the only version of this commitment that holds up against a compelling example.

## What this is, and isn't

**Verifiable directly**: search this project's public repository for any raw record, in any commit, in its history. There isn't one.
