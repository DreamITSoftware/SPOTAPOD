# The FAQ Nobody Asked For: Answering Every Objection to This Project

### A format experiment: stating criticism of the methodology before anyone raises it in the comments

Most research projects answer objections after a critic raises them, in comments or follow-up posts. This piece states the strongest objections to this project's own methodology up front.

## "Isn't this just three cherry-picked datasets?"

Fair concern. These are three specific engagement-pod tool exports, not a random or comprehensive sample of all pod activity or all LinkedIn content. This project has never claimed its findings generalize to "LinkedIn as a whole" beyond what is measurable in these three sources, and every article in this series says which dataset a claim comes from.

## "How do we know the raw data itself is accurate?"

We don't, fully. This project's VERIFIED tier means "independently recomputed from the source file as supplied," not "confirmed accurate against LinkedIn's own internal systems," which this project has no access to. That limitation is documented in this project's limitations.md.

## "Isn't 'engagement pod' just normal networking behavior?"

There is a gray area between mutual, voluntary support among a small professional network and a paid, automated, large-scale reciprocal-engagement service. This project's datasets describe services explicitly built and marketed as the latter (automated, paid, scaled), but the boundary case exists and this project doesn't claim otherwise.

## "Why hide the raw data if you're trying to inform the public?"

A raw record can re-identify a real person even after an obvious name field is removed, and the public-interest value of this research comes from aggregate patterns, not any individual's post. This trade-off is explained at length in this project's privacy.md, and it was a deliberate choice.

## What this is, and isn't

**A transparency exercise, not a new finding.** Where an objection points to a real limitation, it is presented as unresolved.

Full limitations documentation: **github.com/DreamITSoftware/SPOTAPOD**.
