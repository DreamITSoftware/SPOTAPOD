# What This Project Predicted Before It Became a Headline [Template]

### An honest format for tracking whether this project's own inferences turn out right, and just as importantly, when they don't

Research projects love to claim they "called it" after the fact. This piece is a commitment to a format that would make that claim checkable rather than just assertable, including tracking the misses.

## The standard this format holds to

Any future entry in this series names the specific prior INFERENCE or hypothesis from this project's published work, quotes it exactly as originally written (not a retroactively sharpened version), and then evaluates, honestly, whether subsequent events actually confirmed it, contradicted it, or remain genuinely unresolved. A prior inference that turns out wrong gets logged as wrong, in the same format and with the same visibility as one that turns out right.

## Why the wrong ones matter more than the right ones

Anyone can compile a list of their own correct guesses after the fact. It's cheap, because it's a curated sample. A list that also includes the misses is the only version of this format that actually demonstrates calibration rather than selective memory. This project's own "nine of ten" correction, documented elsewhere in this series, is exactly the kind of miss this format would need to include if it had been framed as a prediction rather than a citation error. The discipline is the same either way.

## What qualifies as a genuine "prediction" versus retroactive fit

Only an inference or hypothesis that was explicitly published, dated, and stated as INFERENCE before the relevant later event qualifies for this format. A finding restated with hindsight to sound more prescient than it was at the time doesn't count, and this format explicitly excludes that move.

## What this is, and isn't

**A prepared format and standard, not a completed track record.** No specific instance of a confirmed or disconfirmed prediction is claimed here. This piece exists to commit to the honest version of this format before any specific entry is written.
